Cognomen now runs on more versions of the game.

- **Minecraft 1.21.1** on NeoForge, as before, and now on Fabric.
- **Minecraft 1.20.1, 1.19.2, 1.18.2 and 1.16.5** on Forge and on Fabric.
- **Nothing else is needed.** On Fabric that includes Fabric API.
- **One jar per pair**, named `cognomen-<loader>-<minecraft>-1.2.0.jar`.
- **The config screen is Cognomen's own**, the same on every loader: the name, the skin path and slim arms. The name turns red while it cannot be used. On Forge and NeoForge it is under Mods → Cognomen → Config; on Fabric it opens from Mod Menu when Mod Menu is installed, and otherwise the config file is edited by hand.
- The config file keeps its name and its contents, so the settings from 1.1.0 carry over.
- When the title screen keeps a button on the row Realms leaves, that button now spans the row instead of leaving a gap.

動く Minecraft のバージョンが増えました。

- **Minecraft 1.21.1** は、これまでの NeoForge に加えて Fabric でも動きます。
- **Minecraft 1.20.1・1.19.2・1.18.2・1.16.5** は Forge と Fabric で動きます。
- **ほかに必要なものはありません。** Fabric でも Fabric API は要りません。
- **jar は組み合わせごとに1つ**で、名前は `cognomen-<ローダー>-<Minecraft>-1.2.0.jar` です。
- **設定画面は Cognomen 独自のものになり、どのローダーでも同じです。** 名前・スキンの場所・細い腕を変えられ、名前は使えない間は赤く表示されます。Forge と NeoForge では Mods → Cognomen → 設定 から、Fabric では Mod Menu を入れていればそこから開きます。入れていないときは設定ファイルを直接書き換えます。
- 設定ファイルの名前と中身は変わらないので、1.1.0 の設定はそのまま引き継がれます。
- タイトル画面で、Realms が消えた行にボタンが残るときは、そのボタンを行の幅いっぱいに広げて隙間を作らないようにしました。
