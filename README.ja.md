# Cognomen

[English](README.md)

シングルプレイを、アカウントの名前ではなく自分で決めた名前で遊ぶための Mod です。実況・配信の録画向けで、Microsoft アカウントに紐づいた名前を画面に出さずに済みます。そのために2つ目のアカウントを買う必要もありません。

クライアント専用。Minecraft 1.21.1 / NeoForge 21.1。

## 使い方

**Mods → Cognomen → 設定**で名前を入れるか、`config/cognomen-client.toml` を書き換えます。

```toml
name = "Someone"
```

名前は次に開くワールドから使われます。空欄にすると、アカウント名のまま遊べます。

名前はゲーム本体のプレイヤー名の規則に従います。1〜16文字で、どの文字も空白以外の半角の英数字・記号（`` !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ ``）です。規則に合わない名前は使われず、アカウント名ではなく `player` として遊ぶことになり、そのことを通知で知らせます。

## 仕組み

シングルプレイでは、ゲームはクライアントの中で自前のサーバーを動かしていて、ワールドを開くときにアカウントのプロフィールをそのサーバーに渡します。Cognomen はここで、名前だけを差し替えた写しを渡します。以後サーバーがあなたについて出すものは全部この写しから作られるので、表示を一箇所ずつ直さなくても新しい名前になります。対象は、チャット、参加・退出メッセージ、死亡メッセージ、進捗、コマンドの応答、プレイヤーの頭、署名した本の著者、LAN に公開したときに他の人に見える名前です。

変わらないもの：

- **UUID。** 持ち物・位置・統計・進捗はこの番号で保存されているので、すべてそのまま引き継がれます。
- **スキン。** 写しはアカウントのスキンをそのまま持っていきます。

別に差し替えている箇所が2つあります。エンドポエムは、サーバーではなくアカウントから直接名前を読んでいます。また、ゲームは UUID ごとに前回参加したときの名前を覚えているため、新しい名前で初めて入ると「新しい名前 (formerly known as 前の名前)」と参加を告げてしまいます。シングルプレイのワールドの持ち主については、この前の名前を引かないようにしています。

## 知っておくこと

- **シングルプレイ専用です。** サーバーでは、名前はサーバーから来ます。
- **ワールドに既に書かれた文字は、書いたときの名前のままです。** 名前を打ち込んだ看板、以前に署名した本、プレイヤーの頭、スコアボードの項目（名前で記録されています）には、アカウント名が残ります。
- **ログファイルにはアカウント名が残ります。** `logs/latest.log` には起動時に記録されます。気になる場合は共有しないでください。
