# Cognomen

[English](README.md)

アカウントの名前ではなく、自分で決めた名前で遊ぶための Mod です。実況・配信の録画向けで、Microsoft アカウントに紐づいた名前を画面に出さずに済みます。そのために2つ目のアカウントを買う必要もありません。

クライアント専用。Minecraft 1.21.1 / NeoForge 21.1。

## 使い方

**Mods → Cognomen → 設定**を開くか、`config/cognomen-client.toml` を書き換えます。

```toml
name = "Someone"
skin = "config/cognomen/skin.png"
slimArms = false
```

どちらも次に開くワールドから使われます。名前の初期値は `Steve`、スキンの初期値は空欄で、空欄のときは Steve の見た目になります。

名前はゲーム本体のプレイヤー名の規則に従います。1〜16文字で、どの文字も空白以外の半角の英数字・記号（`` !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ ``）です。空欄の名前や規則に合わない名前は使われず、`Steve` として遊ぶことになり、そのことを通知で知らせます。英数字と `_` だけにしておくのが無難です。実際のアカウント名と同じ文字で、コマンドでも引用符なしで打てます。

`skin` は 64×64 の PNG を、ゲームフォルダからの場所で指定します。`slimArms` を有効にすると細い腕のモデルに貼ります。ファイルが無い、PNG として読めない、大きさが違う、のいずれかのときは Steve の見た目になり、理由を通知で知らせます。

Cognomen を入れている間、アカウント名もアカウントのスキンも使われません。自分のアカウントで遊ぶときは Mod を外してください。

## 仕組み

ゲームはアカウントを、起動から終了まで1つの入れ物に持っています。名前を知りたいものは、この入れ物か、そこから作るプロフィールに問い合わせます。Cognomen はこの2つの問い合わせに設定した名前で答え、プロフィールからアカウントのスキンとマントを外します。そのため、表示を一箇所ずつ直さなくても、その先は全部新しい名前になります。遊んでいるワールド、チャット、参加・退出メッセージ、死亡メッセージ、進捗、コマンドの応答、プレイヤーの頭、署名した本の著者、エンドポエム、LAN に公開したときに他の人に見える名前、それにゲームから名前を読むほかの Mod も含みます。

変わるもの・変わらないもの：

- **UUID は変わりません。** 持ち物・位置・統計・進捗はこの番号で保存されているので、すべてそのまま引き継がれます。
- **見た目は Steve か、設定したスキンになります。** プロフィールにスキンが無いと、ゲームは UUID から既定のスキンを選びます。Cognomen はその既定を Steve に、スキンを設定していればその PNG にします。見た目はこの一箇所から決まるので、自分の姿にも、自分の頭にも、自分を描くほかのものにも届きます。

また、ゲームは UUID ごとに前回参加したときの名前を覚えているため、新しい名前で初めて入ると「新しい名前 (formerly known as 前の名前)」と参加を告げてしまいます。シングルプレイのワールドの持ち主については、この前の名前を引かないようにしています。

## マルチプレイは使えません

サーバーに入るにはアカウント名を伝える必要があるため、Cognomen を入れている間はマルチプレイも Realms も使えません。タイトル画面のマルチプレイと Realms のボタンは、横に出る Realms の通知ごと消してあり、それ以外の経路で接続しようとしたときも、接続せずに案内を出します。

## 知っておくこと

- **ログの冒頭には、アカウント名が残ります。** ランチャーはアカウント名を `--username` としてゲームに渡し、`logs/latest.log` と `logs/debug.log` は、Mod が読み込まれる前にこの起動引数を記録するところから始まります。そのため、どの Mod にも止められません。気になる場合はこれらのファイルを共有しないでください。
- **ワールドに既に書かれた文字は、書いたときの名前のままです。** 名前を打ち込んだ看板、以前に署名した本、以前に作ったプレイヤーの頭、スコアボードの項目（名前で記録されています）には、アカウント名が残ります。
